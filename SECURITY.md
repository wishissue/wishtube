# Security Policy

## Reporting a Vulnerability

We take security and user privacy seriously. If you discover a security vulnerability in WishTube, please report it privately through GitHub's Private Vulnerability Reporting feature, or via email to `TODO_OWNER_EMAIL` if private reporting is unavailable.

Please do not open public GitHub issues for security vulnerabilities until they have been addressed and disclosed.

## Supported Versions

Only the latest stable release of WishTube receives security updates and bug fixes.

## Scope & Protections

WishTube is a local-first client designed to protect user privacy:
- No telemetry, analytics, or tracking SDKs are included.
- All watch history, preferences, and data remain locally stored on device.
- Direct API connections are established with standard HTTP user-agents.
