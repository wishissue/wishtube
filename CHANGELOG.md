# Changelog

All notable changes to WishTube will be documented in this file.

## [Unreleased]

- Initial stabilization and hardening for public release.
- Added mature content setting and client-side safety filters.
- Added Restricted-download license confirmation dialog.
- Hardened OkHttp networking layer with size caps, retries, timeouts, and User-Agent headers.
- Configured CI workflows for automated testing, linting, and GitHub releases.

## [0.1.0] - 2025-01-01

- Initial public release of WishTube unifying PeerTube, Odysee, Internet Archive, media.ccc.de, and Wikimedia Commons.
- Local-first recommendation engine and user profile management.
- Media3 playback engine and offline downloads support.
